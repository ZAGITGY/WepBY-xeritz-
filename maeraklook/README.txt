แม่รักลูก — เว็บร้าน (เวอร์ชัน 2)
เปิดใช้: แตก zip แล้วดับเบิลคลิก index.html ได้เลย ไม่ต้องต่อเน็ต

หน้าเว็บมี 4 ส่วน: หน้าแรก (ฉาก 3D) · สินค้า · เกี่ยวกับร้าน · ติดต่อ + แถบเมนูลัดที่โผล่หลังเลื่อนพ้นหน้าแรก

ไฟล์
- index.html               หน้าเว็บทั้งหมด + token สี/ฟอนต์/ระยะ (บนสุดของ <style>) + แอนิเมชัน GSAP
- assets/js/scene.js       ฉาก 3D ที่ build แล้ว (three.js r187 รวมอยู่ในไฟล์)
- assets/js/gsap.min.js    GSAP 3.15.1
- assets/js/ScrollTrigger.min.js  ปลั๊กอินแอนิเมชันตอนเลื่อนจอ 3.15.1
- assets/fonts/            ฟอนต์ Mali, Prompt (ฝังใน fonts.css มีภาษาไทยครบทุกตัว พิมพ์ข้อความใหม่ได้เลย) + ใบอนุญาต OFL
- assets/og-image.jpg      รูปตอนแชร์ลิงก์ (1200x630)
- assets/apple-touch-icon.png  ไอคอนตอนเพิ่มลงหน้าจอมือถือ
- src/scene.js             โค้ดต้นฉบับของฉาก 3D (แก้ตำแหน่งโมเดลที่ LAYOUT)
- build.sh                 สั่ง build src/scene.js -> assets/js/scene.js (ต้องมี Node.js ครั้งแรกจะติดตั้ง three/gsap/esbuild ให้เอง)

โมเดล 3D: ขวดนม (มีนมข้างใน ขีดบอกปริมาณ ฝาเกลียว) · ของเขย่า (โดมใสมีลูกปัด) · จุกหลอก ·
บล็อก ก ข ค · ห่วงเรียงสีรุ้ง · เป็ดยาง · หัวใจ · ลูกบอล
ระบบจะดันโมเดลไม่ให้ทับเมนู ตัวหนังสือเล็ก และปุ่ม เองทุกขนาดจอ (ทับโลโก้ใหญ่ได้แค่ขอบ)

ลดการเคลื่อนไหว: ถ้าเครื่องตั้ง "ลดการเคลื่อนไหว" ไว้ จะไม่มีแอนิเมชันเลย ทุกอย่างแสดงทันที

ยังรอข้อมูลจากร้าน (ค้นคำว่า "รอข้อมูล" ใน index.html จะเจอทุกจุด)
- รูปสินค้า ชื่อ ราคา (ตอนนี้มีการ์ดตัวอย่าง 6 ใบ เพิ่ม/ลดได้)
- เรื่องราวของร้าน รูปหน้าร้านหรือเจ้าของร้าน และจุดเด่นของร้าน 3 ข้อ
- LINE ID, เบอร์โทร, ที่อยู่, วัน-เวลาเปิดร้าน, ลิงก์ Google Maps
  (ปุ่ม แอดไลน์/โทร/เปิดแผนที่ ยังกดไม่ได้ ใส่ลิงก์ที่ href แล้วลบ aria-disabled="true" ตามคอมเมนต์ในไฟล์)
- หลังขึ้นเว็บจริง: เปลี่ยน og:image เป็น URL เต็ม
