# LVC v10 — ฉากเข้าเว็บจากภาพวิทยาลัย + หน้าแรกที่ขยับอยู่ตลอด (2026-10-26)

## ฉากเข้าเว็บใหม่ (แทนหน้าโหลดโลโก้หมุน)

- เปิดหน้าแรก จะเห็นภาพวิทยาลัยเป็นหุ่นจำลองสีขาวจาง ๆ บนกระดาษ แล้วสีค่อย ๆ ซึมออกแบบสีน้ำ เริ่มจากป้ายชื่อวิทยาลัย ตามด้วยสวน ผนังกระเบื้อง ต้นไม้ เสาธง จนภาพเป็นสีเต็มจอ ชื่อวิทยาลัยขึ้นมุมซ้ายล่าง มีแสงกวาดผ่านหนึ่งครั้ง จากนั้นภาพเลื่อนเข้าไปเป็นพื้นหลังหน้าแรกพอดีกรอบ ม่านจางออก เมนู หัวข้อ และประติมากรรม LVC เปิดตัวต่อ รวมราว 6–7 วินาที
- ตัวเลข % นับตามของที่โหลดเสร็จจริง (ฟอนต์ ภาพวิทยาลัย ประติมากรรม พื้นหลัง) ไม่ได้นับเวลาเปล่า ถ้าเน็ตช้า ภาพจะค้างที่สีเต็มจอจนของพร้อม นานสุด 9 วินาที
- ข้ามได้ด้วยปุ่ม "ข้ามฉากเปิด" หรือปุ่ม Esc ปุ่มข้ามกดได้ตั้งแต่สคริปต์ยังโหลดไม่เสร็จ
- รีโหลดในแท็บเดิม ฉากเล่นเร็วขึ้น 1.6 เท่า · กลับมาจากหน้าอื่นในเว็บ เปิดลิงก์ที่มี #ส่วน หรือเปิด Reduced Motion จะไม่แสดงฉากนี้
- เครื่องที่ไม่มี WebGL หรือภาพโหลดไม่ทันใน 3.5 วินาที ใช้แบบ CSS แทน (ภาพจาง + วงสีเปิดจากป้ายชื่อ)
- กันค้าง: ฉากข้ามตัวเองหลังเริ่ม 13 วินาที และตัวกันพลาดใน `index.html` เปิดหน้าเว็บให้แน่นอนภายในราว 15–18 วินาที
- ไฟล์ใหม่ `intro.js` `campus-gl.js` `campus.css` `images/campus.webp` (ภาพที่ส่งมา แปลงเป็น WebP 341 KB) · ลบ `loader.js` และ CSS หน้าโหลดเดิมแล้ว

## พื้นหลังหน้าแรกไม่โล่งแล้ว (`campus-backdrop.js`)

- ภาพวิทยาลัยแบบสีน้ำอยู่หลังประติมากรรม LVC (คอม: ด้านขวา · มือถือแนวตั้ง: ด้านล่าง) ฝั่งตัวหนังสือยังเป็นภาพจางสีขาว อ่านง่ายเหมือนเดิม
- ขยับตลอดแบบเบา ๆ: ขอบสีหายใจ เมฆลอย ภาพเลื่อนช้า ๆ แสงกวาดผ่านทุก ~14 วินาที
- คอม: ลากเมาส์ผ่าน สีซึมตามเมาส์ · มือถือ/แท็บเล็ต: แตะพื้นที่ว่าง สีบานออกจากจุดที่แตะ และภาพเลื่อนช้ากว่าเนื้อหาเล็กน้อยตอนเลื่อนหน้า
- จางหายเองเมื่อเลื่อนเข้าเรื่องถัดไป กลับมาเมื่อเลื่อนขึ้น · หยุดวาดเมื่ออยู่นอกจอหรือสลับแท็บ
- เครื่องที่วาดไม่ทัน (เฟรมเฉลี่ยช้ากว่า ~46 ms ต่อเนื่อง) ลดความละเอียดก่อน ยังไม่ไหวค่อยเป็นภาพนิ่ง · โหมดประหยัดเน็ต / Reduced Motion = ภาพนิ่ง · ไม่มี WebGL = ภาพ CSS

## แก้บัควงกลม LVC (ช่วงประติมากรรม ตอนประกอบกลับ)

- เดิมเส้นวงกลมกับจุดหัวเส้นขยับคนละจังหวะ จุดวิ่งนำหรือตามหลังเส้น และบน Safari เส้นวาดผิดตำแหน่ง ตอนนี้เส้น หางสีทอง และจุด คำนวณจากมุมเดียวกันทุกเฟรม จุดอยู่ปลายเส้นพอดี (วัดแล้วห่าง 0 px ทุกเฟรม) จุดมีแสงเต้นเบา ๆ
- วงกลมของปุ่มกลับด้านบนมีปัญหาแบบเดียวกันบน Safari แก้แล้ว

## หน้าแรกมีชีวิตหลังโหลดเสร็จ (`alive.js` + `alive.css` ปิดทีละอย่างได้ที่ `CFG`)

- แถบ "ล่าสุดจากวิทยาลัย" เหนือบริการออนไลน์ ข่าว 5 เรื่องจาก lvc.ac.th/www2026 (ตรวจ 26 ต.ค. 2569) เปลี่ยนเองทุก ~4.6 วินาที มีเส้นนับเวลา ปุ่มหยุด ปุ่มถัดไป และลิงก์ข่าวทั้งหมด หยุดเองเมื่อชี้ โฟกัส หรือเลื่อนพ้นจอ
- บริการออนไลน์: เพิ่ม 3 ลิงก์ที่หน้าเว็บวิทยาลัยมีอยู่ (ศธ.02 ออนไลน์ · ศูนย์กำลังคนอาชีวศึกษา · หลักสูตรต้านทุจริตศึกษา)
- แถบชื่อ 8 กลุ่มสาขาวิ่งสวนกันเหนือหัวข้อหลักสูตร ยิ่งเลื่อนหน้าเร็ว ยิ่งวิ่งเร็วและเอียงตาม
- แกลเลอรีผลงานเปลี่ยนภาพเองทุก 6 วินาที มีวงนับเวลาและปุ่มหยุด หยุดเองเมื่อชี้ โฟกัส หรือเลื่อนพ้นจอ
- ตัวเลข 8 กลุ่มสาขา / 3 ระดับ ในช่วงประติมากรรมนับขึ้นเมื่อเลื่อนถึง
- Reduced Motion: ไม่มีอะไรเลื่อนเอง ปุ่มยังกดได้

## อื่น ๆ

- ปุ่มกลับด้านบนแบบลอย (จาก v9.4) เคยทับคำว่า "ก้าวต่อไป" มุมขวาล่างของเรื่องเล่าหน้าแรกบนคอม ตอนนี้หลบไประหว่างช่วงนั้น
- กดข้ามฉากเปิดตั้งแต่ภาพยังไม่พร้อม พื้นหลังจะค่อย ๆ แผ่สีเข้ามาเอง ไม่โผล่มาเต็มสีทันที
- ภาพตัวอย่างเวลาแชร์ลิงก์ (`images/og-cover.jpg`) ทำใหม่จากภาพวิทยาลัย
- ปุ่มเขียวในหน้าต่างแจ้งปัญหาเป็น "ส่งให้ผู้ดูแลทาง LINE": คัดลอกรายงานแล้วเปิด LINE ผู้ดูแล (`lineAdmin` ใน `CFG` ของ `preview-kit.js`) ผู้ทดสอบกดวางในแชตเอง เพราะบัญชีส่วนตัวเติมข้อความให้อัตโนมัติไม่ได้
- ป้าย "แจ้งปัญหา" แนบสถานะฉากเข้าเว็บ (เล่นจบ / กดข้าม / ตัวกันค้าง / แบบ CSS / ไม่แสดง) และพื้นหลัง (ขยับ/นิ่ง ระดับ เฟรมเฉลี่ย) ให้อัตโนมัติ
- ทุกไฟล์ `?v=2026-10-26.10.0`

# LVC v9.4 — แก้บัคก่อนเปิดทดสอบ + การเคลื่อนไหวเสริม + ชุดแจ้งปัญหา (2026-10-25)

## แก้บัค

- **กดโลโก้ / "กลับด้านบน" แล้วไม่กลับขึ้นบนสุด** (หน้าแรก ทั้งคอมและมือถือ) ลิงก์ชี้ไปที่ `#top` ซึ่งเป็นแถบเมนูที่ติดอยู่บนจอตลอด เบราว์เซอร์จึงเลื่อนไปแค่ราว 100px แล้วหยุด ตอนนี้ชี้ไปที่ `#app` (จุดเริ่มหน้า) แล้ว
- **มือถือแนวนอน: ช่วงประติมากรรม LVC มองไม่เห็นข้อความ** ฉากสูงขั้นต่ำ 560px แต่จอแนวนอนสูงราว 360–390px และใช้ผังบน-ล่างของมือถือแนวตั้ง ข้อความ L / V / C จึงหลุดใต้จอ ตอนนี้จอแคบแนวนอนใช้ผังซ้าย-ขวาแบบคอม ย่อตัวหนังสือ และหมุนจอกลับไปมาระหว่างช่วงนี้ได้
- **มือถือ: สถานะชี้ค้างหลังแตะ** ปุ่มเลื่อนผลงานค้างสีทอง แถวหลักสูตรขยับไป 8px และเป็นสีแดง ปุ่มบันทึกขอบแดงค้าง ตอนนี้บนจอสัมผัสจะไม่ค้าง และมีการยุบตัวตอนกดแทน
- ข้อความใต้แฟ้มเอกสารเดิมเขียนว่า "เปิดอ่านได้จากไฟล์ที่ดาวน์โหลดไว้" ซึ่งไม่ตรงเมื่ออัปขึ้นเว็บ เปลี่ยนเป็นคำแนะนำให้เปิด PDF ผ่าน Wi-Fi
- เปิด Reduced Motion แล้วลิงก์ในหน้ายังเลื่อนแบบไหล ตอนนี้กระโดดทันที

## เบาลง

- ฟอนต์ Kanit แปลงเป็น WOFF2: 4 ไฟล์ 680 KB → 198 KB (ตัวอักษรครบเท่าเดิม ตรวจทุก glyph แล้ว) ไฟล์ .ttf ยังอยู่เป็นสำรองสำหรับเบราว์เซอร์เก่า

## การเคลื่อนไหวเพิ่ม (`extras.js` + `extras.css` ปิดทีละอย่างได้ที่ `CFG` บนสุดของไฟล์)

- เส้นความคืบหน้าสีแดง-ทองใต้แถบเมนู ยาวตามการเลื่อน (ทุกหน้า)
- ปุ่มกลับด้านบนลอยมุมขวาล่าง มีวงบอกว่าอ่านไปแค่ไหน ซ่อนตัวระหว่างช่วงประติมากรรม และยกตัวเหนือแถบเปรียบเทียบในหน้าหลักสูตร
- กดปุ่มบนมือถือแล้วปุ่มยุบตัวเล็กน้อย แถวลิงก์จางลงตอนแตะ
- ตัวอักษร LVC เส้นทองขนาดใหญ่ท้ายทุกหน้า ไหลขึ้นทีละตัวเมื่อเลื่อนถึง
- แสงนวลตามเมาส์ในช่วงผลงาน (คอมเท่านั้น)
- ตราวิทยาลัยบนแถบเมนูเอียงเล็กน้อยเมื่อชี้ (คอม)
- รูปข่าว/ผลงานจางเข้าเมื่อโหลดเสร็จ เน็ตช้าจะไม่เห็นรูปค่อย ๆ โผล่ทีละครึ่ง
- ช่องค้นหาสาขาเปลี่ยนตัวอย่างคำค้นทุก ~3 วินาที (หยุดเมื่อแตะช่องหรือพิมพ์)
- โหลดหน้าถัดไปล่วงหน้าเมื่อชี้/แตะลิงก์ เปลี่ยนหน้าเร็วขึ้น (ปิดเองเมื่อเปิดโหมดประหยัดเน็ต)

## สำหรับช่วงทดสอบ

- **ป้าย "ฉบับทดลอง · แจ้งปัญหา"** กลางขอบล่างของจอ (`preview-kit.js`) กดแล้วผู้ทดสอบเลือกประเภท เขียนสิ่งที่เจอ แล้วกด "คัดลอกรายงาน" หรือ "ส่งทาง LINE" รายงานแนบรุ่นเครื่อง เบราว์เซอร์ ขนาดจอ โหมดสว่าง/มืด ตำแหน่งในหน้า และข้อผิดพลาด JavaScript ที่จับได้ให้อัตโนมัติ ไม่มีการส่งข้อมูลไปไหนเอง อยากให้มีปุ่มส่งอีเมลหรือเปิด Google Form ให้ใส่ใน `CFG` บนสุดของไฟล์
- **`<meta name="robots" content="noindex">`** ทุกหน้า กัน Google เก็บฉบับทดลองไปปนกับเว็บทางการ
- **ภาพตัวอย่างเวลาแชร์ลิงก์** (`images/og-cover.jpg` 1200×630) และไอคอนตอนเพิ่มลงหน้าจอโฮม iPhone
- **`404.html`** หน้าลิงก์เสียในสไตล์เดียวกับเว็บ (GitHub Pages / Netlify / Cloudflare Pages ใช้อัตโนมัติ)
- ทุกไฟล์มี `?v=2026-10-25.9.4` รวม `style.css` ที่เดิมไม่มี ผู้ทดสอบที่เคยเปิดรุ่นเก่าจะไม่ติดแคช

## ก่อนส่งลิงก์ให้คนอื่น

1. อัปทั้งโฟลเดอร์ขึ้นโฮสต์ที่เป็น **https** (GitHub Pages / Cloudflare Pages / Netlify) แล้วเปิดลิงก์บนมือถือตัวเองหนึ่งรอบ
2. แก้ `content="./images/og-cover.jpg"` ใน 4 ไฟล์ HTML เป็น URL เต็ม เช่น `https://ชื่อเว็บ/images/og-cover.jpg` (LINE / Facebook ไม่อ่าน path แบบสั้น) แล้วลองวางลิงก์ในแชต LINE ของตัวเองดูภาพตัวอย่าง
3. ถ้าจะรับรายงานทางอีเมลหรือ Google Form ใส่ใน `CFG` ของ `preview-kit.js`
4. ตอนเปิดใช้จริง: ลบ `<script src="./preview-kit.js">` และบรรทัด `robots noindex` ออกจากทั้ง 4 หน้า

ไฟล์ใหม่: `extras.js`, `extras.css`, `preview-kit.js`, `404.html`, `fonts/*.woff2`, `images/og-cover.jpg`, `images/apple-touch-icon.png` · ไฟล์ที่แก้: 4 หน้า HTML, `app.js` (ลิงก์ `#top` → `#app` 3 จุด), `lvc-showcase.js`, `showcase.css`, `style.css`, `enhance.css`, `assets/glass-folder/documents.js` และ `source/components/lvc-documents.tsx` (ข้อความใต้แฟ้ม)

# LVC v9.1 — แฟ้มเอกสารกระจกและโหมดหน้าจอ

ชุดนี้รวมเว็บไซต์พร้อมเปิดใน Spck, ซอร์ส React + TypeScript + Tailwind CSS พร้อมโครงสร้าง shadcn/ui และเอกสารจริงจากวิทยาลัยสำหรับอ่านออฟไลน์

## เปิดใช้งานใน Spck

หน้าเว็บพร้อมใช้อยู่ที่รากของ ZIP ส่วน `source/` ใช้สำหรับพัฒนาส่วน React บนเครื่องที่มี Node.js ดูคำสั่ง `npm ci`, `npm run build` และ `npm run dev` ใน `source/README-TH.md`

ดีไซน์ใช้โทนขาวงาช้าง แดง และทองเหลืองอ่อน (champagne) ตัวอักษรหัวข้อใหญ่น้ำหนักเบา และประติมากรรม LVC เป็นจุดเด่นเพียงจุดเดียวของหน้าแรก ผิวหน้าเคลือบสีแดง เนื้อทรงสีงาช้าง ขอบเฉียงโลหะสีแชมเปญ และฐานลอยเพรียวบาง อ้างอิงวิดีโอที่ตรวจดูแล้วผ่านภาพตัวอย่าง `design-refs/video-contact-sheet.jpg`

มือถือหมุนประติมากรรมตามการเลื่อนโดยไม่ตรึงฉาก เมื่อเปิด Reduced Motion จะแสดงเนื้อหาและประติมากรรมแบบนิ่ง การแสดงข้อความไม่ต้องรอ WebGL

## ใหม่ในรุ่น .8 — เมนูตรงกับสิ่งที่เลือก และโมเดลไม่สั่น

- เส้นแดงใต้เมนูมีเพียงรายการเดียว การชี้เมาส์เปลี่ยนเฉพาะสีข้อความ ไม่เพิ่มเส้นแดงอีกเส้น
- ระหว่างเลื่อนไปยังส่วนที่เลือก จะไฮไลต์เมนูที่กดล่าสุด ไม่ไล่ติดทุกส่วนระหว่างทาง เส้นเก่าหายทันทีเมื่อเลือกใหม่
- ยกเลิกการเลื่อนเดิมเมื่อผู้ใช้เลื่อนเอง และใช้ตำแหน่งใต้แถบเมนูเป็นจุดอ่านส่วนปัจจุบัน
- โมเดลใช้กรอบตำแหน่งคงที่ การเอียงตามเมาส์จึงไม่ผลักโมเดลด้านข้าง
- เปลี่ยนการหมุนให้ต่อเนื่องตามสกรอลล์ ลดการโยกหลายแกนและซูมเข้าออก ขณะเลื่อนจะค่อย ๆ คืนการเอียงจากเมาส์
- ยังคงฉากเล่าเรื่อง การย้ายฝั่ง และการแยกชิ้นส่วนช่วงเทคนิคไว้

ใช้ไฟล์ ZIP รุ่น .8 แทนทั้งโครงการ แล้วรีโหลด Preview เพื่อให้เบราว์เซอร์ใช้สคริปต์ล่าสุด

## ใหม่ในรุ่น .7 — เลื่อนลื่นและหน้าโหลดใหม่

- แก้แอนิเมชันสองชุดที่ควบคุมการตัดขอบรูปเดียวกันใน `app.js` และ `scroll-fx.js`
- เนื้อหาแต่ละรายการค่อย ๆ ชัดและยกขึ้นเล็กน้อยเพียงครั้งเดียว จะแสดงค้างเมื่อเลื่อนกลับ ปรับขนาดจอ หรือคำนวณตำแหน่งใหม่
- ยกเลิกม่านเปิดรูปที่ยาว การขยายกรอบผลงานตามสกรอลล์ และ parallax ภาพถ่าย เพื่อลดการเคลื่อนไหวซ้อนกัน
- หน้าโหลดเพิ่มข้อความต้อนรับ หมุนโมเดลเบาลง และเปลี่ยนเข้าหน้าแรกกระชับขึ้น แถบความพร้อมอิงสถานะทรัพยากรเป็นขั้นตอน ไม่ใช่จำนวนไบต์ดาวน์โหลด
- แกลเลอรีไม่รอแอนิเมชันปาดภาพ และป้องกันเหตุการณ์โหลดรูปเก่ากลับมาเล่นซ้ำเมื่อกดเร็ว
- ปุ่มและโมเดลเคารพการเปิด Reduced Motion ระหว่างใช้งานทันที
- คงฉากเล่าเรื่องหน้าแรกบนคอมไว้ ซึ่งข้อความเปลี่ยนตามแต่ละช่วงของการเลื่อนโดยตั้งใจ

**ใช้งานใน Spck:** แตก ZIP หรือ Import ZIP เข้าโครงการใหม่ แล้วเปิด `index.html` ผ่าน Preview ได้เลย ไม่ต้องติดตั้งแพ็กเกจหรือ build หากแทนโครงการเดิม ให้แทนไฟล์ทั้งชุดและรีโหลดพรีวิวเพื่อไม่ให้ใช้แคชเก่า

รายละเอียดรุ่น .6 และเก่าด้านล่างเป็นประวัติการทำงาน บางเอฟเฟกต์ถูกแทนที่ในรุ่น .7 แล้ว ผลทดสอบล่าสุดอยู่ต้นไฟล์ `QA.md`

## ใหม่ในรุ่น .6

**1) หน้าโหลดหมุนพอดี** (`loader.js`) — โมเดลวิ่งเข้ามาพร้อมหมุนประมาณ 1/3 รอบ (เดิมหมุนหลายรอบต่อเนื่อง) แล้วชะลอลงจนนิ่งที่มุมเดียวกับหน้าแรก โยกช้า ๆ รอเล็กน้อย แล้ววิ่งกลับไปจอดที่เดิม ตัดตัวเลข % ใหญ่ตัวหนังสือ LVC โครงเส้น ตารางกริด และแสงสีแดงของหน้าโหลดเดิมออก เหลือจอมืดโทนอุ่น แสงสปอตบาง ๆ เส้นความคืบหน้าบางเส้นเดียว
- ปรับปริมาณการหมุน: `entrySpin` ใน `CFG` บนสุดของ `loader.js` (หน่วยเรเดียน · 2.2 ≈ 1/3 รอบ · ใส่ 0 = ไม่หมุนเลย · 6.28 = 1 รอบ)
- ข้ามได้ด้วยปุ่ม "ข้ามหน้าโหลด" หรือ Esc · ไม่แสดงเมื่อเปิด Reduced Motion, URL มี `#anchor` หรือ `?noloader` · บังคับแสดงด้วย `?loader` · ไม่มี WebGL จะใช้ภาพสำรองทำท่าเดียวกัน (ทดสอบด้วย `?no-webgl`)

**2) ปุ่มโลหะเหลว** (`metal-button.js`) — คอมโพเนนต์ "Liquid Metal Button" ที่ส่งมาเป็น React + Tailwind + shadcn ซึ่งเว็บนี้ไม่ได้ใช้ จึงพอร์ตเป็น JavaScript ล้วนโดยใช้ไลบรารี Paper Shaders ตัวเดียวกัน แล้วปรับให้เข้ากับงานของเรา: ขอบโลหะสีแชมเปญเดียวกับขอบตัวอักษร 3 มิติ หน้าปุ่มแดงเคลือบ (ปุ่มหลักหน้าแรก) และสีงาช้าง (ปุ่ม "สมัครเรียน" บน header) โลหะไหลช้า ๆ เร็วขึ้นเมื่อชี้ มีระลอกตอนกด ยังเป็นลิงก์ `<a>` เดิม ใช้คีย์บอร์ดได้ มีวงโฟกัส · Reduced Motion = ขอบนิ่ง · ไม่มี WebGL = ขอบไล่สีนิ่ง ๆ

**3) เรียบหรูขึ้น ไม่ดูเป็น "AI slop"** (`enhance.css`) — ตัดของที่เป็นแค่ลายตกแต่งออก: ป้ายเล็กเหนือหัวข้อพร้อมเส้นและเลข 01/02/03, ข้อความคั่นด้วยจุดกลาง, ตัวหนังสือ LVC โครงเส้นและวงกลมลอยหลังโมเดล, ตารางกริด, ตัวนับซ้ำ, เลขหน้าแถวหลักสูตร, วงกลมรอบลูกศร, แถบตัวหนังสือวิ่ง และเส้นความคืบหน้าสีแดงที่เคยเพิ่มในรุ่น .5 · เหลืองสดเปลี่ยนเป็นทองเหลืองอ่อน · หัวข้อใช้ Kanit Light · ส่วนผลงานแดงเข้มขึ้น · ข้อความเล็กสุดไม่ต่ำกว่า 12px · ช่องไฟระหว่างส่วนกว้างขึ้น · ปรับโทนสีรูปถ่ายเล็กน้อยให้เป็นชุดเดียวกัน (เนื้อหาใน `app.js` ยังอยู่ครบ แค่ไม่แสดง)

**4) อนิเมชันเพิ่ม (ตั้งใจให้ "น้อยแต่แพง")** — ใช้ภาษาการเคลื่อนไหวแค่ 3 แบบทั้งเว็บ ไม่ใช้เลื่อนขึ้น-จางเข้าทุกอย่าง:
- **เส้น** — เส้นบาง ๆ ลากเข้ามาใต้หัวข้อ ระหว่างแถวหลักสูตร/ข่าว ในข้อมูลสาธารณะ และฟุตเตอร์
- **ม่านบัง** — หัวข้อไหลขึ้นจากเส้นตัดทีละบรรทัด (เว้นที่ให้วรรณยุกต์ไทยไม่ถูกตัด) และรูปภาพถูกยกเปิดเหมือนม่าน
- **จาง** — ย่อหน้าค่อย ๆ ชัดขึ้นอย่างเดียว
- ตอบสนองผู้ใช้: โมเดลหน้าแรกเอียงตามเมาส์ไม่เกิน ~5° และแสงขยับตาม (`hero-motion.js` · เฉพาะเมาส์จริง จอ > 900px) · เมนูบน header ขีดเส้นใต้ส่วนที่กำลังอ่าน · กดลูกศรเปลี่ยนรูปผลงานแล้วรูปปาดเข้ามา · ปุ่มโลหะมีระลอกตอนกด · ลิงก์ข้อความมีเส้นใต้วิ่งผ่านตอนชี้
- ยังมี: parallax รูปถ่ายเบา ๆ (จอ > 900px) และส่วนผลงานสีเข้มที่ขยายออกเต็มจอ
- ปิด/เปิดทีละอย่างได้ที่ `FX` บนสุดของ `scroll-fx.js` · Reduced Motion = ทุกอย่างปิด · ถ้า `scroll-fx.js` โหลดไม่สำเร็จ เว็บกลับไปใช้อนิเมชันเดิมของ `app.js`

ไฟล์ที่เพิ่ม: `loader.js`, `scroll-fx.js`, `metal-button.js`, `hero-motion.js`, `enhance.css`, `vendor/paper-liquid-metal.js`, `fonts/kanit-300.ttf` · ไฟล์ที่แก้: `index.html` และ `app.js` (เพิ่ม hook เล็ก ๆ 6 จุด) — ดูรายละเอียดใน `PATCH-NOTES.md`

**ข้อควรรู้:** ชุดนี้แก้ที่ไฟล์ build แล้ว (`app.js` ที่ย่อไว้) ไม่ได้แก้ใน source project ถ้าจะ build ใหม่จาก `LVC-v4-source.zip` ต้องย้าย hook 6 จุดไปใส่ใน source ก่อน ไม่เช่นนั้นหน้าโหลด ปุ่มโลหะ และการเอียงตามเมาส์จะไม่ทำงาน (เว็บเดิมยังใช้ได้ปกติ) ดู `PATCH-NOTES.md`

## แบบที่ 1: ZIP สำหรับ Spck Editor / โฮสต์เว็บ

ใช้ไฟล์ `LVC-v6-luxe-Spck.zip` (รุ่นนี้มีเฉพาะ ZIP แยกไฟล์ ยังไม่ได้ทำ HTML ไฟล์เดียวและ source ZIP ของรุ่น .6)

1. แตก ZIP หรือนำเข้า ZIP เป็นโปรเจกต์ใน Spck Editor ตามเมนูของรุ่นที่ใช้อยู่
2. ให้ `index.html`, `app.js`, `loader.js`, `scroll-fx.js`, `metal-button.js`, `hero-motion.js`, `style.css`, `enhance.css`, โฟลเดอร์ `vendor/`, `images/` และ `fonts/` อยู่ด้วยกันตามโครงสร้างเดิม
3. เปิด `index.html` แล้วใช้ Preview / Run ของ Spck
4. ไม่ต้องติดตั้ง Node.js, npm หรือรัน build

ไฟล์นี้เป็นชุดที่พร้อมแสดงผลแล้ว หากต้องการแก้เนื้อหาและโครงสร้างโค้ดต้นฉบับ ให้ใช้ `LVC-v4-source.zip` แล้ว export ใหม่ ไม่ควรแก้ JavaScript ที่ย่อไว้ใน `app.js` โดยตรง

## อัปขึ้นเว็บและส่งลิงก์ให้ผู้ทดสอบ

- แตก ZIP แล้วอัป **ทุกไฟล์และทุกโฟลเดอร์ข้างใน** ไปยัง static hosting
- วาง `index.html` ที่หน้าแรกของโฟลเดอร์ที่จะเผยแพร่ เช่น `/lvc-preview/index.html`
- รองรับทั้งรากเว็บไซต์และโฟลเดอร์ย่อย โดยไม่ต้องแก้ path ของภาพหรือฟอนต์
- ตัวอย่างบริการที่รองรับไฟล์ static: GitHub Pages, Cloudflare Pages หรือโฮสต์เว็บทั่วไป
- เมื่อโฮสต์เผยแพร่สำเร็จแล้ว ให้ส่ง URL ที่โฮสต์ออกให้แก่ผู้ทดสอบ
- ไม่ต้องใช้ PHP, ฐานข้อมูล หรือ backend

## สิ่งที่ควรให้ผู้ทดสอบลอง

1. หน้าโหลด: รีเฟรชแล้วดูว่าจำนวนที่หมุน "พอดี" ไหม โมเดลจอดตรงที่เดิมของหน้าแรกโดยไม่วูบ ลองปุ่มข้าม / Esc และหมุนจอมือถือระหว่างโหลด
2. ปุ่มโลหะ: ชี้ กด และกด Tab ดูวงโฟกัส ตรวจว่าปลายทางลิงก์ถูกต้อง ลองบนมือถือเครื่องเก่าว่าลื่นไหม
3. Desktop: ขยับเมาส์บนโมเดลหน้าแรก (เอียงตาม) แล้วเลื่อนผ่านภาพระยะใกล้ การแยกชั้นในฉากเทคนิค และการประกอบกลับ แล้วเลื่อนย้อนขึ้น
4. เลื่อนดูหัวข้อ เส้น และรูปภาพที่เปิดแบบม่านยก ตรวจว่าข้อความอ่านได้ระหว่างเคลื่อนไหว ไม่มีส่วนไหนค้างโปร่งใส ลองเลื่อนเร็ว ๆ ขึ้น-ลง และลองกด Tab ข้ามส่วนที่ยังไม่โชว์
5. มือถือ: เปิดเมนู เลือกบริการ ลองแนวตั้งและแนวนอน
6. กดปุ่มรับสมัคร หลักสูตร ข่าว และบริการออนไลน์ ตรวจว่าปลายทางตรงกับข้อความ
7. เลื่อนภาพผลงาน (ดูการปาดเปลี่ยนรูป) เปิดภาพเต็ม แล้วปิดด้วยปุ่มหรือ Escape
8. ตรวจวรรณยุกต์ไทย ข้อความที่ถูกตัด ภาพล้นขอบ และปุ่มกดยาก
9. ทดลองเปิด Reduced Motion ในระบบ และลองเติม `?no-webgl` ท้าย URL เพื่อดูภาพสำรอง

ใช้ `BUG-REPORT.md` จดอุปกรณ์ ขั้นตอนทำซ้ำ สิ่งที่พบ สิ่งที่คาดหวัง และแนบภาพหน้าจอ ไม่มีการส่งข้อมูลผู้ทดสอบอัตโนมัติ

## ข้อจำกัดที่ทราบ

- ตรวจรายงาน `QA.md` สำหรับผลทดสอบที่ทำจริงและขอบเขตของแต่ละเวอร์ชัน ยังไม่ได้เปิดแพ็กเกจนี้ในแอป Spck บนอุปกรณ์จริง และไม่ได้วัดอัตราเฟรมบนมือถือจริง จึงไม่อ้างประสิทธิภาพ 60fps จากการทดสอบใน Chromium (ใช้ WebGL แบบซอฟต์แวร์)
- หน้าโหลดและปุ่มโลหะใช้ WebGL เพิ่ม (หน้าโหลดสร้างอีก 1 canvas เต็มจอราว 5 วินาทีแล้วทิ้ง · ปุ่มแต่ละปุ่มมี canvas เล็ก 1 อัน) บนเครื่องที่ GPU อ่อนมากให้ใช้ `?noloader` หรือลบ `<script src="metal-button.js">`
- ข้อความคำขวัญ หัวข้อ และเนื้อหาเดิมไม่ได้ถูกเขียนใหม่ (แก้เฉพาะการนำเสนอ) ถ้าต้องการให้ปรับถ้อยคำให้ดูหรูขึ้นด้วย บอกได้
- การทดสอบการเปิด `file://` โดยตรงถูกนโยบายของ browser ใน environment นี้บล็อก จึงไม่อ้างว่าทดสอบวิธีเปิดนั้นผ่านแล้ว
- ต้องใช้ browser / Android WebView ที่รองรับ JavaScript สมัยใหม่ หาก WebGL ใช้ไม่ได้จะแสดงภาพประติมากรรมสำรองและขอบปุ่มแบบนิ่ง
- ปุ่มรับสมัครพาไปช่องทางติดต่อของวิทยาลัย เพราะยังไม่ได้ยืนยัน URL สมัครโดยตรง
- ข่าวและหลักสูตรเป็นข้อมูล snapshot ส่วนระบบ RMS และบริการทางการยังเป็นลิงก์ภายนอก
- แพ็กเกจนี้ไม่ได้สร้าง URL สาธารณะให้อัตโนมัติ ต้องอัปขึ้นโฮสต์ก่อนแชร์เป็นลิงก์
