# โมเดลตัวการ์ตูนเดินเล่น (`assets/pet/sweetie-belle.glb`)

ไฟล์ในโฟลเดอร์นี้ใช้สร้างโมเดลที่ `lvc-pet.js` โหลด จากไฟล์ Blender ใน `sweetie-belle.zip` ที่เจ้าของเว็บส่งมา (ไม่ได้เก็บ .blend ไว้ใน repo เพราะใหญ่ ~15 MB และจะถูกเผยแพร่ไปกับเว็บ)

## สร้างใหม่

```bash
pip install bpy==5.2.3            # Blender เป็นโมดูล Python (ต้องใช้ Python 3.13)
source/pet/make.sh "<โฟลเดอร์ที่แตก zip>/source/甜贝儿.blend"
# หรือระบุ Python เอง: BLENDER_PY=/path/to/python3.13 source/pet/make.sh ...
```

ได้ไฟล์ทับ `assets/pet/sweetie-belle.glb` แล้วเปลี่ยน `VERSION` ใน `lvc-pet.js` (และ `?v=` ในหน้า html) เพื่อล้างแคช

## `build_pet.py` ทำอะไร

1. **เก็บกวาด**: ลบชุดสำเนาในคอลเลกชัน "Please delete" (`头.001` `瞳孔.001` `高光.001`) แล้วย้ายหัว/ตาดำ/ประกายตาตัวจริงที่มี shape key (วางเยื้องไว้ 0.7) กลับเข้าที่ ลบเมชสีหน้าที่ไม่ใช้ (น้ำตา เส้นเหนื่อย ฯลฯ)
2. **อบโมดิไฟเออร์**: Mirror + Solidify (เส้นขอบแบบ inverted hull) + Subdivision ระดับ 1 ใส่ลงเมชจริง โดยเก็บ shape key ที่ใช้ไว้เป็น morph target:
   `happyEyes` (笑眼) `blink` (轻闭眼) `smile` (微笑) `laugh` (大笑) `squeeze` (紧闭) `open` (小张嘴) `browsUp` (抬眉) และ `blush` (脸红)
3. **วัสดุ**: เดิมเป็นสีเรียบไม่รับแสง ส่งออกเป็นสี/เท็กซ์เจอร์ธรรมดา วัสดุเส้นขอบตั้งชื่อขึ้นต้น `OL_` ให้ฝั่งเว็บรู้ เท็กซ์เจอร์ย่อเหลือกว้าง 1024 px (WebP)
4. **ท่าทาง** (ขยับตัวควบคุม IK ของ rig เดิม แล้วให้ exporter อบเป็นกระดูกที่ใช้จริง):
   - `Idle` 2 วิ วนซ้ำ — หายใจ เอียงหัว แขนแนบตัว
   - `Walk` 1 วิ วนซ้ำ — 2 ก้าว ก้าวละ 0.2 หน่วย (เท้าเลื่อนบนพื้น 0.4 หน่วย/วิ ที่ความเร็ว 1×)
   - `Happy` 1.08 วิ ครั้งเดียว — ย่อตัว กระโดด ยกแขน
   - `Held` 1 วิ วนซ้ำ — ยกแขน เท้าแกว่ง (ตอนถูกลาก)
5. ส่งออก GLB (กระดูกที่ deform เท่านั้น)

`make.sh` ต่อด้วย gltf-transform: dedup → prune → resample → `prune_rest.mjs` (ลบช่องอนิเมชันที่อยู่ท่าพักตลอดคลิป) → meshopt (บีบอัด) ได้ไฟล์ราว 1.4 MB

## ข้อควรรู้เกี่ยวกับ rig นี้

- ตัวควบคุมเอว `腰控制器` ถูก copy rotation ไปที่กระดูกสันหลัง 4 ท่อน หมุน 5° ตัวจะเอนราว 13° จึงใช้มุมเล็กมาก
- ข้อมือคุมด้วย `小臂IK.*` (ลูกของ `肩膀IK.*`) ปลายมือคุมด้วย `手掌IK.*` ต้องย้ายทั้งคู่ ไม่อย่างนั้นมือจะชี้ออกข้าง
- เท้าคุมด้วย `小腿IK.*` (ลูกของกระดูกราก) ลดสะโพก `骶椎` ลงมากเกิน ~0.03 เข่าจะงอมาก
- ห้ามใช้ `export_optimize_animation_keep_anim_armature=False` เพราะจะทิ้งกระดูกที่ค้างท่าเดียวทั้งคลิป (เช่นแขนตอน Held) แล้วแขนเด้งกลับเป็นท่า T จึงใช้ `prune_rest.mjs` แทน ซึ่งลบเฉพาะช่องที่ตรงกับท่าพักจริง ๆ
