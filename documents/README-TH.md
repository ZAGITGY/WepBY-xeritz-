# เอกสารวิทยาลัยสำหรับอ่านออฟไลน์

ไฟล์ในโฟลเดอร์นี้เป็นสำเนาเอกสารต้นฉบับจากเว็บไซต์วิทยาลัยอาชีวศึกษาเลย เก็บไว้โดยไม่แก้ไขเนื้อหา เพื่อเปิดอ่านได้เมื่อไม่มีอินเทอร์เน็ต

- `student-handbook-2569.pdf` — คู่มือนักเรียน นักศึกษา ปีการศึกษา 2569 (56 หน้า)
- `certificate-plan-2569.pdf` — แผนการเรียนระดับ ปวช. ปีการศึกษา 2569 (57 หน้า)
- `diploma-plan-2569.pdf` — แผนการเรียนระดับ ปวส. ปีการศึกษา 2569 (84 หน้า)
- `no-gift-policy-2569.pdf` — นโยบายไม่รับของขวัญ (1 หน้า)
- `dos-and-donts-2569.pdf` — ข้อควรทำและไม่ควรทำ (8 หน้า)
- `complaints-guide-2569.png` — คู่มือการร้องเรียน

ที่มา ขนาดไฟล์ และ SHA-256 ของทุกไฟล์อยู่ใน `sources.json` ตรวจสอบไฟล์วันที่ 14 ตุลาคม 2569 เอกสารออนไลน์ต้นทางอาจมีการปรับปรุงภายหลัง สำเนาชุดนี้คงเนื้อหาที่ตรวจสอบไว้ในวันดังกล่าว

การเปิด PDF อาจใช้โปรแกรมอ่านเอกสารของเครื่อง ส่วนการส่งเรื่องร้องเรียนและบริการออนไลน์ต้องเชื่อมต่ออินเทอร์เน็ตและใช้เว็บไซต์ทางการ

## หมายเหตุรุ่น v9.2

ชุดที่ส่งมาตรวจไม่มีไฟล์ `student-handbook-2569.pdf` (ประมาณ 25.5 MB) ลิงก์คู่มือทุกจุดจึงเปิดต้นฉบับจากเว็บไซต์วิทยาลัยแทนโดยอัตโนมัติ (`doc-links.js`) หากต้องการอ่านออฟไลน์ ให้วางไฟล์คืนในโฟลเดอร์นี้ด้วยชื่อเดิม แล้วลิงก์จะกลับมาเปิดไฟล์ในเครื่อง
