# ใบเสร็จรัก (Love Receipt)

เว็บเซอร์ไพรส์คู่รัก เปิดมาเป็นเครื่องพิมพ์ใบเสร็จ กด "พิมพ์ใบเสร็จ" แล้วกระดาษค่อยๆ ไหลออกมา
รายการในใบเสร็จคือความทรงจำของคู่นั้น ท้ายใบมีบาร์โค้ด แตะแล้วข้อความลับขึ้นเต็มจอ

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `index.html` | ตัวเว็บทั้งหมด ข้อมูลลูกค้าอยู่ใน `CONFIG` บนสุดของไฟล์ |
| `photos/` | รูปของแต่ละรายการ (ตัวอย่างเป็นภาพวาด SVG) |
| `promo.mp4` | คลิปโปรโมต TikTok 1080x1920 · 20 วิ · มีเพลง + เสียงเอฟเฟค |
| `promo-src/` | ไฟล์ต้นฉบับของคลิป **ไม่ต้องส่งให้ลูกค้า** |

ลูกค้าแต่ละคนใช้แค่ **`index.html` + โฟลเดอร์ `photos/`**

---

## ทำเว็บให้ลูกค้าใหม่ (แก้ CONFIG ที่เดียว)

เปิด `index.html` จะเจอ `const CONFIG = { ... }` อยู่บนสุด (ประมาณบรรทัด 20) ทุกช่องมีคอมเมนต์ภาษาไทยบอกไว้

| ช่อง | ใส่อะไร | ตัวอย่าง |
|---|---|---|
| `nameA`, `nameB` | ชื่อสองคน → ชื่อร้านบนหัวใบเสร็จ | `"เบส"`, `"เมย์"` |
| `sender` | คนให้ → "แคชเชียร์" | `"เบส"` |
| `recipient` | คนรับ → "มีใบเสร็จส่งถึง ..." | `"เมย์"` |
| `startDate`, `startTime` | วันเริ่มคบ (ปี ค.ศ.-เดือน-วัน) → เลขที่ใบเสร็จ + ตัวนับ | `"2024-02-14"`, `"00:00"` |
| `items` | รายการความทรงจำ 5–8 รายการ | ดูด้านล่าง |
| `total`, `paidWith`, `change` | ยอดรวม / ชำระด้วย / เงินทอน | `"∞"`, `"ทั้งใจ"` |
| `secret` | ข้อความลับ: `title`, `lines` (ทีละบรรทัด), `signature` | |
| `music` | ไฟล์เพลง (ไม่บังคับ) ไม่เล่นเอง ต้องกดปุ่ม | `"song.mp3"` |
| `theme` | พื้นหลัง `pastel` / `linen` / `blush` / `wood` + สีหลัก + สีพื้นข้อความลับ | `"pastel"`, `"#b04a7a"` |
| `doodles` | ลายวาดจางๆ บนพื้น เลือกจากรายการในคอมเมนต์ (หัวใจ แมว หมวก เมฆฝน เรือไฟ ทุเรียน ฯลฯ) | `["cat", "heart"]` |
| `stamp` | ตราประทับสีแดงบนใบเสร็จ หลังพิมพ์เสร็จ (`""` = ไม่มี) | `"ชำระแล้ว"` |
| `sound` | เสียงเอฟเฟคตอนกดพิมพ์/ตัดกระดาษ/ประทับตรา/สแกน มีปุ่มปิดเสียงมุมขวาบน | `true` |
| `printSpeed` | ความเร็วพิมพ์ 1 = ปกติ (~10 วิ) | `1` |

แต่ละรายการใน `items`:

```js
{
  date: "14/02/24",                 // พิมพ์ตามที่เขียน (จำไม่ได้ ใส่ "" ชื่อเรื่องจะชิดซ้ายเอง)
  title: "กาแฟแก้วแรกของเรา",
  note: "คุยกันจนพนักงานเริ่มเก็บเก้าอี้",   // ไม่ใส่ก็ได้
  price: "ประเมินค่าไม่ได้",           // คำหวานแทนราคา
  photo: "photos/01.jpg",           // ไม่ใส่ก็ได้
  alt: "เราสองคนนั่งร้านกาแฟริมหน้าต่าง",  // มีรูปต้องใส่ อธิบายว่าในรูปมีอะไร
},
```

**ข้อควรระวังตอนแก้**
- ข้อความต้องอยู่ใน `"..."` และท้ายบรรทัดมี `,` เหมือนตัวอย่าง อย่าลบ `{ }` หรือ `[ ]`
- ถ้าแก้แล้วหน้าเว็บว่าง แปลว่าเครื่องหมายหายไปสักตัว ย้อนดูบรรทัดที่เพิ่งแก้
- รูปใช้ `.jpg` หรือ `.png` กว้างราว 1000–1600 px ไม่ต้องแต่งขาวดำเอง เว็บแปลงเป็นเม็ดสกรีนให้
- รูปจาก iPhone/iPad มักเป็น `.heic` (Chrome เปิดไม่ได้) แปลงก่อน: แอป **Files** → แตะรูปค้าง → **Quick Actions** → **Convert Image** → JPEG
- ตั้งชื่อรูปง่ายๆ เป็นภาษาอังกฤษ ไม่มีเว้นวรรค เช่น `01.jpg` `beach.jpg` แล้วใส่ชื่อเดียวกันใน `photo`

## ขึ้น GitHub Pages ด้วย Safari บน iPad

ทำครั้งละ 1 ลูกค้า = 1 repo (ใช้บัญชี GitHub ฟรีได้)

**1. สร้าง repo**
1. เข้า github.com → ล็อกอิน → แตะ **+** มุมขวาบน → **New repository**
2. ตั้งชื่อ เช่น `faii-0214` (ชื่อนี้จะอยู่ในลิงก์) → เลือก **Public** → **Create repository**

**2. อัปโหลด `index.html`**
1. ในหน้า repo ใหม่ แตะลิงก์ **uploading an existing file**
2. แตะ **choose your files** → เลือก `index.html` จากแอป Files → **Commit changes**

**3. สร้างโฟลเดอร์ `photos` แล้วอัปรูป**
1. หน้า repo → **Add file** → **Create new file** → ช่องชื่อพิมพ์ `photos/.keep` → **Commit changes**
2. แตะเข้าโฟลเดอร์ `photos` → **Add file** → **Upload files** → เลือกรูปทั้งหมด → **Commit changes**

**4. แก้ CONFIG**
1. แตะ `index.html` → แตะรูปดินสอ (Edit this file)
2. แก้ชื่อ วันที่ รายการ ข้อความลับ → **Commit changes**

**5. เปิดเว็บ**
1. หน้า repo → **Settings** (ถ้าไม่เห็น แตะ **⋯** ก่อน) → เมนูซ้าย **Pages**
2. **Source** เลือก **Deploy from a branch** → **Branch** เลือก `main` และ `/ (root)` → **Save**
3. รอ 1–2 นาที แล้วรีเฟรช จะขึ้นลิงก์ `https://ชื่อผู้ใช้.github.io/ชื่อrepo/`
4. เปิดลิงก์ทดสอบให้จบทั้งเรื่อง (กดพิมพ์ → แตะบาร์โค้ด) แล้วค่อยส่งให้ลูกค้า

> แก้ไขทีหลังก็ได้ แก้ไฟล์แล้ว Commit รอ 1–2 นาที เว็บอัปเดตเอง (ถ้ายังเห็นของเก่า ปิดแท็บแล้วเปิดใหม่)

**เรื่องความเป็นส่วนตัว:** repo แบบ Public ใครมีลิงก์ก็เปิดดูรูปได้ บอกลูกค้าก่อน และตั้งชื่อ repo ไม่ให้เดาง่าย
เลือกรูปที่ลูกค้ายินดีให้ขึ้นเว็บเท่านั้น

## ใส่เพลง (ถ้าลูกค้าอยากได้)

อัปไฟล์ `.mp3` ไว้ที่เดียวกับ `index.html` แล้วใส่ `music: "song.mp3"`
จะมีปุ่ม "เปิดเพลง" มุมขวาบน เพลงไม่เล่นเองจนกว่าคนเปิดลิงก์จะกด · ใช้เพลงที่มีสิทธิ์ใช้เท่านั้น

## อื่นๆ

- ถ้าเครื่องคนเปิดตั้งค่า "ลดการเคลื่อนไหว" (Reduce Motion) ใบเสร็จจะโชว์เต็มทันที ไม่มีอนิเมชัน
- เสียงเอฟเฟคสร้างในเบราว์เซอร์ ไม่ต้องอัปไฟล์เสียง ดังหลังคนเปิดลิงก์กดปุ่มเท่านั้น (บน iPhone ถ้าเปิดโหมดเงียบไว้จะไม่ได้ยิน)
- เปิด `index.html` ตรงๆ จากไฟล์ในเครื่อง รูปจะเป็นขาวดำธรรมดา ไม่เป็นเม็ดสกรีน ขึ้นเว็บจริงแล้วจะเป็นเม็ดสกรีนปกติ
- บาร์โค้ดเป็น Code 128 ของจริง สแกนแล้วได้เลขวันเริ่มคบ
- ฟอนต์ IBM Plex Mono + IBM Plex Sans Thai จาก Google Fonts (SIL Open Font License)

## ทำคลิปโปรโมตใหม่ (สำหรับร้าน ไม่เกี่ยวกับลูกค้า)

อยู่ใน `promo-src/` ใช้คอมที่มี Node 22, ffmpeg, Playwright, Python 3 + numpy

```bash
cd love-receipt && python3 -m http.server 8765   # เปิดค้างไว้อีกหน้าต่าง
cd love-receipt/promo-src
node capture-site.cjs            # อัดหน้าเว็บทีละเฟรม → site.mp4 + site-events.json
python3 make-sfx.py              # สร้างเสียงเอฟเฟคตามจังหวะในคลิป → assets/sfx.wav
npx hyperframes@0.9.20 render -q delivery -f 30 --video-frame-format png -o ../promo.mp4
```

ข้อความในคลิปแก้ได้ที่ `promo-src/index.html` · เพลงอยู่ที่ `promo-src/assets/music.mp3` (ความดังปรับที่ `data-volume` ของ `<audio id="music">`)
เสียงเอฟเฟคทั้งหมดสังเคราะห์เองใน `make-sfx.py` ไม่ได้ใช้ไฟล์เสียงของใคร
